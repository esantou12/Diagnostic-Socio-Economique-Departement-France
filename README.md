# Diagnostic-Socio-Economique-Departement-France
Analyse statistique des disparités socio-économiques entre départements français à partir des données INSEE
Présentation du projet

Ce projet vise à analyser les disparités socio-économiques entre les départements français à partir de données publiques de l'INSEE.

L'objectif est d'identifier les différences territoriales en matière de pauvreté, de niveau de vie, d'inégalités et de composition des revenus.

Problématique

Dans quelle mesure les départements français présentent-ils des profils socio-économiques différents et quels facteurs permettent de caractériser ces disparités territoriales ?

Sources de données

INSEE – Filosofi 2023 : niveaux de vie, pauvreté, inégalités et composition des revenus.

D'autres sources statistiques publiques seront intégrées progressivement pour enrichir le diagnostic.

Méthodologie

Collecte et exploration des données.

Nettoyage et préparation des données.

Analyse descriptive et statistique.

Étude des relations entre les indicateurs.

Enrichissement avec des indicateurs relatifs à l'emploi.

Visualisation et analyse territoriale.

Technologies utilisées

Python

Pandas

NumPy

Matplotlib

Seaborn

Jupyter Notebook

Power BI (prévu)

Premiers résultats

Les premières analyses mettent notamment en évidence :

Une corrélation négative entre le niveau de vie médian et le taux de pauvreté.

Une corrélation positive entre le taux de pauvreté et la part des prestations sociales.

Une forte association entre l'indice de Gini et le rapport interdécile.

Des différences territoriales dans la composition des revenus.

État d'avancement
